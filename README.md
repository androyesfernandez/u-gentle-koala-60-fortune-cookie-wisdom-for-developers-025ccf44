One original fortune-cookie line for a software developer. `main.ts` writes the
line to `/output/entry.txt` — a single sentence, 79 characters, no trailing
newline. A tired senior engineer would nod at it: a test that passes for the
wrong reason is a bug that has already passed its interview.
